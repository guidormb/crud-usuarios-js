# CRUD Usuarios JS - por Guido

Proyecto hecho 100% desde el celular con Spck Editor.

**Demo:** https://crud-usuarios-js-npvu.vercel.app/
**Repo:** https://github.com/guidormb/crud-usuarios-js

### Funciones
- Crear, editar y eliminar usuarios
- Buscar por nombre/email
- Ordenar por ID, nombre y edad
- Promedio de edad y contador
- Exportar / Importar JSON
- Guardado en localStorage

### Tech
HTML, CSS, JavaScript (módulos ES)

### Cómo correr
Solo abrir index.html, no necesita servidor.
